# Catino UI Refactor Instructions

## 1. Brand Direction

Catino must feel:
- Warm
- Modern
- Clean
- Slightly premium
- Campus-friendly (not childish)

Avoid:
- Neon colors
- Gaming-style glow effects
- Fintech-style dark dashboards
- Random gradients

Design for appetite, clarity, and trust.

---

## 2. Color System (Strict Usage Rules)

### Primary Brand Color
**Orange — #E85002**

Use ONLY for:
- Primary buttons (Add, Checkout)
- Active navigation state
- Price emphasis
- Selected states
- Important badges

### Support Colors
- Green → Success only (minimal usage)
- Red → Errors and destructive actions
- Grayscale → Structure, text, borders

Do NOT:
- Mix multiple button colors
- Use neon tones
- Use random yellow/lime accents

Color discipline = brand trust.

---

## 3. Layout & Visual System

### Backgrounds
- Default: White
- Dark surfaces only where intentional
- No random gradients

### Border Radius
- 16px everywhere (cards, buttons, inputs)

### Shadows
- One subtle elevation style
- No heavy or glowing shadows

### Spacing
- Use 8px spacing grid system
- Maintain consistent padding across screens

---

## 4. Home Screen Structure

- White background
- Clear section headers
- Clean food cards
- Consistent spacing
- No heavy contrast blocks

Remove:
- Dark gradients
- Mixed button colors
- Excess visual noise

---

## 5. Food Card Structure

Card Layout:
1. Food image (top)
2. Title (bold, black)
3. Short description (gray)
4. Price (orange)
5. Small rounded orange “Add” button

Remove:
- Black card backgrounds
- Mixed badge colors
- Over-designed elements

Keep it minimal and breathable.

---

## 6. Bottom Navigation

- Frosted glass allowed (subtle)
- Active icon → orange indicator
- Inactive icons → muted gray
- Small notification badge
- No glow effects

Navigation must feel calm and controlled.

---

## 7. Cart & Checkout Screen

Structure:
- Clean white card
- Clear item breakdown
- Large bold total
- Full-width orange Checkout button

Avoid:
- Green total highlights
- Neon emphasis
- Visual clutter

Checkout must feel decisive and trustworthy.

---

## 8. Order History Screen

- Clean dark or neutral surface
- Simple status badges
- Small green check for success
- No decorative gradient shapes

Focus on clarity and readability.

---

## 9. Typography System

Define and stick to:
- H1
- H2
- Body
- Caption

Rules:
- Consistent font family
- Defined size scale
- Clear hierarchy
- No random size jumps

---

## 10. Non-Negotiable Consistency Rules

Standardize:
- Border radius (16px)
- Shadow style (single system)
- Button height
- Typography scale
- Spacing system (8px grid)

No screen should feel visually different from the others.

---

## 11. Fundable Product Standard

The UI must communicate:
1. Scalability
2. Trust
3. Brand cohesion
4. Design maturity

Refactor the entire system.
Do not patch screens individually.

Build a design system — not a collection of screens.
